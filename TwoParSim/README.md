1. Generate shared object for `SIRfun.c` to run the ODE as a C library, this can be done by running `sh UbunCreateSO.sh` to create the library using gcc (assuming you have gcc on your device).  On Compute Canada hardware you must run generate the C library again on the cluster.
2. Simulate brute force attractor data by running `SimTwoParDataSharc.R`.  This file is meant to be run on Compute Canada/other HPIC.  The script to send this script to SLURM is `SimTwoParJob.sh`.  Takes a long time (days) but only needs to be run once.  This will generate the `bfd/bfd_*.rds` files (`*` is from 1 to 10).
3. Estimate transient periods for the period 1 and 2 attractors using `find_transients.R`, which can be run locally and takes about 2 hours.  This will generate the `Transients/Transient*.rds` files (`*` is from 1 to 2).
4. Obtain the trajectory that the sinusoidally forced macpan2 model goes through in $(\mathcal{R}_0, \alpha)$ space by running `CreateTraj.R`, which generates the files `firstInds.rds` (the first indices in the scarlet fever time series data corresponding to each break segment), `lastInds.rds` (the last indices in the scarlet fever time series data corresponding to each break segment), `simTrajectory.rds` a data frame containing the value of the trajectory at times 1842:1939 + 0.5 where we'd like to do many brute force simulations to get basins of attraction, and `trajectory.rds`, a data frame containing the trajectory at every single time point in our scarlet fever time series data.  This script can be run locally and is quick (less than a minute).
5. Run `SimTwoParTraj.R`, which runs the simulations to get basins of attraction at the years in `simTrajectory.rds`.  This script is meant to be run on Compute Canada/other HPIC.  The script to send this script to SLURM is `SimTwoParTrajJob.sh`.  Takes roughly 2 hours to run.  This will generate the `bfd/sim_trajectory_*.rds` files (`*` is from 1 to 10).
6. Run `find_transients_traj.R` which estimates the transient periods of the simulations that converged to period 1 attractors in `simTrajectory.rds`, takes roughly 2 hours.  This generates `Transients/Transient1_trajectory.rds`.
7. Run `CreateYearlyTraj.R`, which combines the transient trajectory data with the simulated trajectory data to create `yearly_trajectory.rds`, containing all of the yearly attractor and transient data.

This is how many of the `*.rds` files in the `Plots/Data` directory of the manuscript were generated.
